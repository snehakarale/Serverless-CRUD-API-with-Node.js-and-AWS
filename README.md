# Serverless-CRUD-API-with-Node.js-and-AWS

In this project, we will build a serverless CRUD API using AWS services. The goal is to create an API that allows you to perform Create, Read, Update, and Delete operations on data stored in a DynamoDB table. This API will be exposed through API Gateway, and the backend logic will be powered by AWS Lambda functions. The entire solution will be serverless, meaning there is no need to manage infrastructure such as servers or databases manually.
